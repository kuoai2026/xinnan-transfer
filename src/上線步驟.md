- 後端 `Code.gs`（綁在「藥局調貨表單」試算表的 Apps Script）

- deploy key：`~/.ssh/xinnan-transfer-deploy(.pub)`、SSH 別名 `github-xinnan-transfer`（已寫入 `~/.ssh/config`）

## 1. 建 GitHub repo（你操作）

1. GitHub 新建 **public** repo：`kuoai2026/xinnan-transfer`（不要加 README）。
2. repo → Settings → Deploy keys → Add deploy key：
   - Title：`mac-cron`
   - Key：貼下面這串
     ```
     ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIKBIpjMZmXJb0f7IehZDemf49CweQm+ZaE58wYY69fM1 xinnan-transfer deploy key
     ```
   - ☑ **Allow write access**
3. repo → Settings → Pages → Source 選 `Deploy from a branch`、branch `main` / `/ (root)`、Save。

## 2. 首次推送（我幫你做，或你自己跑）

```bash
cd ~/repos/xinnan-transfer
GIT_SSH_COMMAND="ssh -i ~/.ssh/xinnan-transfer-deploy -o IdentitiesOnly=yes" git push -u origin main
```

網址：**https://kuoai2026.github.io/xinnan-transfer/**

## 3. 部署 Apps Script（你操作）

1. 開「藥局調貨表單」試算表 → 擴充功能 → Apps Script。
2. 把 `Code.gs` 全部內容貼進去（覆蓋 `Code.gs`）。存檔。
   - 貼不進去時：先全選刪光，再貼。
3. 編輯器上方選函式 `setup` → 執行一次 → 跳授權就同意（會建立「調貨單_主檔」「調貨單_明細」兩個分頁，並取得寄信權限）。
4. 右上「部署」→「新增部署作業」→ 類型「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**任何人**
   - 部署 → 複製「網頁應用程式」的 `…/exec` 網址。
5. 之後每次改 `Code.gs` 要「管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，網址不變。

## 4. 把 endpoint 填回設定，重建

把上一步的 `/exec` 網址貼進 `transfer_page/config.json` 的 `"endpoint"`，然後我重跑 `deploy.sh`（或）：

```bash
bash ~/我的雲端硬碟/scripts/transfer_page/deploy.sh
```

## 備註

- **搜不到純藥局品牌**（挺立舒、中衛口罩、泰達椅收納袋…）：這些網翼裡沒有，門市用「系統沒有的商品」自由填，倉庫端會標「系統沒有」。
- **可售庫存**顯示的是網翼盤點表的「可售庫存」（已扣蝦皮未出貨預留），一天更新兩次（05:00→08:30重建、12:40→12:50重建）。
- **token**：`config.json` / `Code.gs` 各有一份要一致。repo 是公開的，所以 token 會出現在 index.html 裡——它只擋隨機網路噪音，不是真的機密。真要更嚴，改成「只有 Google 登入的人可存取」但門市就得先登入 Google。
- 舊的「表單回應」分頁完全不會被動到。
